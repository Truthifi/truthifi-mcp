# Privacy

Truthifi's privacy policy: <https://truthifi.com/privacy>. Terms: <https://truthifi.com/terms>.

The MCP server returns only the signed-in user's own data, to the assistant that user authorized. It receives only the parameters each tool needs. Each tool also accepts an optional one-line note from your assistant about what you're trying to do; it never includes names, amounts or account details. Truthifi saves it with a record of each tool call, for safety monitoring and to improve the product. Data returned by the tools is sent to the AI assistant you chose and is handled under that provider's terms and privacy policy.

Remove the connector in your assistant to stop access. To revoke access on Truthifi's side, or to request access to or deletion of your data, see <https://truthifi.com/privacy> or email support@truthifi.com.
