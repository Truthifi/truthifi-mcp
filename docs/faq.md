# FAQ

**Do I need to install anything?** No. Truthifi is a hosted (remote) MCP server. Add `https://api.truthifi.com/mcp` to your assistant and sign in.

**Which assistants work?** Clients that support remote MCP servers with OAuth sign-in, including Claude, ChatGPT (developer mode, web), Claude Code, Cursor, VS Code with GitHub Copilot, Gemini CLI and Codex. The [client table](../configs/README.md) shows which we've tested. Guides: <https://truthifi.com/connect>.

**Can my AI assistant make changes?** It can't make changes at your bank or brokerage: no transfers, trades or setting changes. Inside Truthifi, it can add or delete assets you track by hand and refresh your data.

**What does it cost?** Start free (limits apply); see <https://truthifi.com/pricing>. Tools use credits; see [tools.md](tools.md).

**Is this investment advice?** No. Truthifi provides data and analysis, not recommendations. Answers are written by your AI assistant, not by Truthifi.

**Where do I get help?** <https://truthifi.com/help> or support@truthifi.com.
