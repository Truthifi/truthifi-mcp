# Contributing

This repository is Truthifi's official MCP documentation, maintained by Truthifi. Spotted a mistake? Open a *Documentation correction* issue or email support@truthifi.com. For account help, use the help center: <https://truthifi.com/help>.

Opening this repository in Claude Code, Cursor or VS Code may prompt you to connect the Truthifi server from `.mcp.json`. You can decline; it isn't needed to edit the docs.
